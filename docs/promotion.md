## 中文版（掘金 / V2EX / 知乎 / 公众号）

**标题：我开源了一个 AI 学习批注助手 —— 边读边标注，AI 即时回答，读完自动出复习题**

学习时是不是经常这样：读教材划重点，笔记记了一堆却没人解答；学完想复习，又不知道从哪出题？

我开源了 **StudyWise** —— 一个把「阅读 + 批注 + AI 答疑 + 复习」放进同一张页面的学习工具：

- 📖 **单页学习工作区**：内容、笔记、AI 对话三栏并排，不用在多个标签页来回切换
- ✍️ **选中即批注**：任意选中一段文字，添加笔记或提问，自动高亮
- 🤖 **AI 即时回复**：支持多 Provider（火山引擎 DeepSeek / OpenAI / Claude），选中问题直接得到解答（流式输出）
- 📝 **自动总结 + 复习题**：学习完成后一键生成知识总结和复习题，自测巩固
- 💾 **本地优先**：SQLite 存储，数据完全在你掌控中

技术栈：Next.js 14 + TypeScript + TailwindCSS + Drizzle ORM + SQLite，MIT 开源，CI 全绿。

仓库已设为 **Template**，一键复制即可二次开发，适合当作业、毕设或作品集项目。

🔗 https://github.com/free1101/studywise

如果觉得有用，点个 ⭐ 支持一下，欢迎提 issue / PR！

## English (Reddit / Hacker News / X / Product Hunt)

**StudyWise — an open-source AI study companion. Read, annotate, and learn on a single page.**

Ever highlight a textbook, jot down questions, and never get answers? StudyWise puts reading, annotation, AI answers, and review into one workspace:

- Single-page learning workspace — content, notes, and AI chat side by side
- Select any text → add a note or question → auto-highlight
- Instant AI replies (streaming) with multiple providers (Volcengine DeepSeek / OpenAI / Claude)
- Auto-generate summaries and review quizzes when you're done
- Local-first with SQLite — your data stays yours

Built with Next.js 14 + TypeScript + TailwindCSS + Drizzle ORM + SQLite. MIT licensed, CI green, and set as a **GitHub Template** — clone it and make it yours.

🔗 https://github.com/free1101/studywise

Star ⭐ appreciated. Issues & PRs welcome!
